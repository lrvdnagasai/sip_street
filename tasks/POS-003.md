# Environment Configuration

Create a `.env` file with the following variables.

```
APP_NAME=C3 Cafe POS
APP_VERSION=1.0.0
DEBUG=True
DATABASE_URL=sqlite:///./database/c3_pos.db
```

Configuration must be loaded using **pydantic-settings**.
