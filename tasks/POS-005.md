---

# Objective

Build the database foundation for the C³ Cafe POS backend.

This task establishes the database architecture and connection management for all future modules.

No business models or tables should be created.

---

# Functional Requirements

The application should:

- Connect successfully to SQLite
- Create a reusable database session
- Initialize the database during application startup
- Close database sessions properly
- Provide a reusable Base model
- Expose database dependency injection for future APIs
- Verify database connectivity

---

# Technical Requirements

Use

- SQLAlchemy 2.x
- SQLite
- Alembic

Follow FastAPI best practices.

Use SQLAlchemy ORM.

No raw SQL.
